# Fixed-world evaluation

世界座標を合わせ、全条件で同じROI・格子・閾値を使います。既定ROIはX=[-12,12]、Y=[8,32]、Z=[-8,88] mm、格子0.2 mm、閾値128です。ROIを条件ごとに最適化しません。再構成前景のvoxel中心がROI外にある出力は評価を中止します。必要なROIは実験の前に共通設定として決めてください。

評価格子の座標は各軸で `ROI_min+(index+0.5)*voxel_mm`。入力画像の画素中心規約とは別です。再構成の `index_to_world_mm` の逆行列で評価格子を出力indexへ写し、三線形補間します。SciPy `map_coordinates(order=1, output=uint8, prefilter=False)` を使い、範囲外は0。補間後のuint8を128で閾値化します。

真値は世界座標で `x²+(y-20)²≤4²` かつ `0≤z<80` の円柱です。

## Metrics

- **生IoU**: 真値と再構成前景の交差体積/和集合体積。主指標です。
- **平行移動補正IoU**: 前景の3D重心を真値中心 `(0,20,40)` mmに合わせて1回だけ平行移動した補助値。強度を三線形補間して同じ閾値で判定し、IoUを最大化する探索はしません。
- **XY断面中心**: 各世界XY断面で、前景画素の面積重心を求めます。真値中心 `(0,20)` mmとの誤差 `e(z)` を評価します。
- **平均偏り**: `mean(e)` のX/Y成分とそのノルム。
- **中心RMSE**: `sqrt(mean(||e||²))`。平均偏りを含みます。
- **中心変動**: `sqrt(mean(||e-mean(e)||²))`。平均偏りを除きます。
- **最大偏差**: `max(||e||)`。
- **検出率・未検出率**: 真値長さ内の全断面に対する検出/未検出の割合。
- **Z重心移動**: 再構成3D重心のZ成分、および同経路・速度の遅延0対照との差。

中心統計は真値長さ内 `0≤z<80` の**検出できた断面だけ**で計算します。この区間の全断面が未検出なら、平均偏り・中心RMSE・中心変動・最大偏差はJSON `null`、CSVでは空欄です。未検出を0誤差として扱いません。

補正IoUと3D重心は、共通ROI全体の閾値化した前景で定義します。評価格子上のROI全体に前景がない場合だけ `null` になります。前景が真値長さの外側だけにある場合も計算するので、その場合は検出率0・中心統計 `null` でも、補正IoUは数値を持ちます。これは大きな平行移動を補助的に評価するためです。主指標の生IoUと検出率は補正しません。

世界XYのRMSEはZ方向への移動を含まないため、IoU・重心・検出率を併用します。

遅延0でも取得・再構成・格子・閾値による誤差があり得ます。同経路・速度の遅延0、同seedの遅延0、同遅延の欠損なし対照からの差を保存します。直線等速の検算は `δ=v*k/30` mm、理想円柱のIoUは `(80-δ)/(80+δ)`。実際の離散化結果をこの式へ合わせて補正しないでください。

## Interpretation

再構成アダプターの補間・融合・穴埋め・厚み・平滑化設定は結果に影響します。方法と欠損方針を揃えたrun内で比較し、他の実装との数値的一致を前提にしません。断面画像の生成法も結果に影響するため、入力アダプターの画素中心・単位・輪郭誤差を検証してください。

5 pose欠損は各走査の合計数で、連続欠損長5という指定ではありません。8 seedの平均・min/maxは限定的な感度試験であり、信頼区間や長期の実機性能を示しません。未来poseを利用した補間の結果を、因果的なオンライン処理の評価として扱わないでください。
